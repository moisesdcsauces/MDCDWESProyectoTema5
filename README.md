Ejercicios del Tema 5 sobre control de acceso: variables superglobales y autenticación del usuario con la función header() y con una tabla Usuario de la base de datos.

## Ejercicios

| Nº | Ejercicio |
|:--:|-----------|
| 0 | [Variables superglobales y phpinfo()](codigoPHP/ejercicio00PDO.php) |
| 1 | [Control de acceso con la función header()](codigoPHP/ejercicio01PDO.php) |
| 2 | [Control de acceso con header() y la tabla Usuario de la base de datos](codigoPHP/ejercicio02PDO.php) |

## Estructura

- `indexProyectoTema5.php`: índice con todos los ejercicios.
- `codigoPHP/`: ejercicios.
- `config/`: configuración de la conexión a la base de datos.
- `core/`: librería de validación de formularios.
- `mostrarCodigo/`: páginas que muestran el código de cada fichero.
- `scriptsDB/`: scripts para crear, cargar y borrar la base de datos.
- `webroot/`: hojas de estilo.
- `error/`: páginas de error 404 y 403 del proyecto.
- `.htaccess`: índice del proyecto y páginas de error.

## Tecnologías

PHP 8 (PDO), MariaDB, HTML5 y CSS3, servidor Apache.

## Ramas

- `master`: version entregada.
- `developerMDC`: rama de trabajo.
